Hướng dẫn cài đặt và chạy (XAMPP)
1. Copy thư mục `quanlyhoadon` vào `C:\xampp\htdocs\`.
2. Khởi động Apache và MySQL bằng XAMPP Control Panel.
3. Mở phpMyAdmin (http://localhost/phpmyadmin) và tạo cơ sở dữ liệu `quanlyhoadon`.
4. Import file `create_tables.sql` trong thư mục dự án để tạo bảng và dữ liệu mẫu.
5. Mở trình duyệt vào: http://localhost/quanlyhoadon/index.php
