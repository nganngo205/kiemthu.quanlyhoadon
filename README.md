Hướng dẫn cài đặt và chạy (XAMPP)
Copy thư mục quanlyhoadon vào C:\xampp\htdocs\.
Khởi động Apache và MySQL bằng XAMPP Control Panel.
Mở phpMyAdmin (http://localhost/phpmyadmin) và tạo cơ sở dữ liệu quanlyhoadon.
Import file create_tables.sql trong thư mục dự án để tạo bảng và dữ liệu mẫu.
Mở trình duyệt vào: http://localhost/quanlyhoadon/index.php
